My objective with **YAPS**(**Y**es **A**nother **P**ngtuber **S**oftware) is to give more interactive and features to anyone ho use a PngTuber our GifTuber, so then can connect the program to Twitch directly or
use programs like [Streamer.bot](https://streamer.bot/) to create interactive or automations to your stream.

## Features
- Drag and drop images and gif`s as assets
- Spout2 integration
- Use mic volume for switch to a specific expression
- Websocket server
- Position presets
- Twitch integration
